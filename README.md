HuggingHack lets you manage AI models from the Hugging Face Hub on your own computer. You can browse available models, pick the specific files you need, and store them on your hard drive or network storage. This tool helps you keep your AI collection tidy and ready for use.

## 📥 How To Get HuggingHack

1. Open your web browser.
2. Visit the [official download page](https://github.com/qasidah7544/HuggingHack).
3. Look for the latest version under the Releases section on the right side of the screen.
4. Click the file ending in .exe to start your download.
5. Save the file to your computer desktop.

## ⚙️ System Requirements

Make sure your computer meets these needs before you run the software:

* Operating System: Windows 10 or Windows 11.
* Memory: 8 GB of RAM or more.
* Storage: At least 500 MB of free disk space for the app itself.
* Connection: A stable internet connection to fetch model files.

## 🚀 Setting Up The Software

Follow these instructions to install and prepare HuggingHack:

1. Locate the file you saved to your desktop.
2. Double-click the file to start the installer.
3. Follow the prompts on the screen. Windows might ask for permission to run the tool. Click Yes to proceed.
4. Choose the folder where you want to keep your library. Pick a drive with plenty of space if you plan to download large models.
5. Wait for the green progress bar to finish.
6. Click Finish to launch the app.

## 🛠️ Using The Interface

The main window shows a list of models from the Hub. Use the search bar at the top to find a specific model by name. 

When you click on a model, the app displays a list of files. Use the checkboxes to select only the files you require. This approach saves space because you do not need to download the entire model folder if you only need one file.

Click the Download button to start the transfer to your local folder. You can see the speed and remaining time for each file in the bottom panel.

## 📁 Managing Your Library

HuggingHack creates a structured folder system. Every model organizes itself into a subfolder. This makes it easy to find your files for other projects later.

To remove a model, right-click the item in your library list and select Delete. The app asks you to confirm your choice before it removes the files from your hard drive.

## 🔧 Resolving Common Issues

If the app fails to open, restart your computer and try again. Ensure no other applications are using the same download folder. 

If you see an error about your internet connection, verify your Wi-Fi or Ethernet status. HuggingHack requires a connection to talk to the Hugging Face servers.

Ensure Windows Firewall allows the application to access the internet. Usually, the first time you run the app, a window pops up asking for network access. Click Allow.
